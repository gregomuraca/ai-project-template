# No Slop

**Status:** tested

## Purpose

Make writing sound owned by a person rather than generated by a generic model.

The goal is not maximum compression and not a fixed "human" style. The goal is to remove patterns that weaken specificity, credibility, rhythm, or voice.

## Use when

- editing AI-assisted writing;
- cleaning professional copy, emails, case studies, web copy, or applications;
- reviewing text for generic LLM patterns;
- tightening a draft without changing its core argument.

## Do not use when

- the user wants only factual analysis;
- the requested voice intentionally uses a flagged pattern;
- a change would remove factual nuance, necessary qualification, or domain terminology.

## Editing sequence

1. Identify the intended audience, register, and purpose.
2. Separate factual claims from interpretation or recommendation.
3. Detect slop patterns.
4. Make the minimum effective edit.
5. Compare the result against the original for meaning and voice.
6. Run an adversarial final pass: did the edit create new slop?

## Slop categories

### Lexical

Flag when they add little information:

- empty intensifiers;
- inflated verbs where a plain verb is more precise;
- generic praise;
- vague business nouns such as "impact," "value," "solution," or "outcomes";
- stock AI/business language such as "delve," "leverage," "seamless," or "transformative."

Do not ban words mechanically. A word is a problem only when it is weak in context.

### Structural

Inspect:

- generic openers;
- excessive setup before the real point;
- repetitive summaries;
- over-signposting;
- forced three-part lists;
- repeated "not X, but Y" constructions;
- engineered pull-quote language;
- conclusions that restate the piece and add vague optimism.

### Semantic

Flag:

- claims that sound impressive but say little;
- abstractions where a concrete action or result is available;
- capability inventories without evidence;
- sentences that imply causality, ownership, or scale beyond the source material.

### Epistemic

Protect:

- uncertainty;
- scope;
- attribution;
- confidence;
- distinction between fact, inference, and opinion.

Never make a claim stronger merely to make the prose cleaner.

### Voice

Preserve:

- contractions;
- sentence-length variation;
- deliberate fragments;
- humor;
- directness;
- technical vocabulary;
- characteristic phrasing.

A polished sentence that no longer sounds like the writer can be a regression.

## Preferred replacements

Prefer:

- concrete action over vague capability;
- evidence over adjectives;
- actor + action over hidden responsibility when agency matters;
- direct statements over ceremonial setup;
- one strong example over a list of generic examples.

## Anti-pattern

Do not perform this transformation mechanically:

```text
natural but imperfect
→ shorter
→ smoother
→ more formal
→ generic
```

The correct objective is:

```text
natural but imperfect
→ clearer and more specific
→ same person
```

## Quality gate

Before returning edited text, ask:

1. Did I remove anything that carried meaning?
2. Did I strengthen a claim without evidence?
3. Did I make the writer sound more generic?
4. Did I introduce formulaic contrast, triads, or unnecessary signposting?
5. Is every substantive edit solving a real problem?

If the original wording is already effective, leave it unchanged.
